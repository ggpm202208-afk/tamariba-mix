# MIX バランス確認

MGO2PC の MIX（12人）で「バランス悪いから振り直したい」を、誰が言い出したか分からない形で確認するための1ページツール。

## 使い方

1. 配布URLをDiscordに貼る（`?c=` を付けるとその合言葉の集計に入る）
2. 各自が同じURLを開く。コードも参加操作もない
3. 「振り直したい」が3票に達すると、全端末で同時に結論が出る
4. 結論はDiscord Webhookにも自動で流せる（設定から1回だけ登録）

## 仕組み

- 静的ファイル1枚。サーバー・DB・ビルドなし
- 投票は公開リレー（ntfy.sh）で全端末に配信され、**各端末が同じログを同じ順序で再生**して同じ結論を出す
- 時刻は端末の時計ではなくリレーが付けた時刻を使うので、時計がずれても結論が割れない
- 集計役（ホスト）がいないので「誰が始めたか」が発生しない
- Webhook送信は、Webhookを持つ端末のうちID最小の1台だけが行う（二重投稿なし）

## ローカルで開く

`index.html` をダブルクリックでOK。ファイル直開きでも同期します（`file://` はCORSが `Origin: null` 扱いですが、ntfyとDiscordの両方が受け付けます）。

## 設定

| 項目 | 場所 |
|---|---|
| 合言葉 | URLの `?c=xxx` か、ページ内「設定」 |
| Discord通知 | ページ内「設定」にWebhook URLを貼る（その端末のlocalStorageにのみ保存） |

Discord側: チャンネル設定 → 連携サービス → ウェブフック → 新しいウェブフック → URLをコピー。

## 注意

- URLを知っていれば誰でも同じ合言葉に入れる。配布先に注意
- リレーの保持は約12時間（日替わり運用向け）
- Webhook URLはページに含まれないため、閲覧者が勝手に投稿することはできない
